## Правила

- Один `dist/index.html` обслуживает ленту, каталог, «Буду смотреть» и годноту.
- Карточки общие: крупные постеры, сердце справа, маленький номер слева на постере. Постер открывает трейлер, название — описание.
- Каталог: нерешённые по номеру. Лента: случайно. Папич — отдельный явный фильтр.
- Вправо — сохранить трейлер, влево — исключить. Зелёный просмотренный лайк справа добавляет в годноту, красный слева исключает. Вертикальный пропуск откладывает.
- Профиль общий в D1 через `/api/profile`; localStorage — кэш. Проверить API прежде, чем утверждать, что отметки недоступны.
- Не выдумывать отзывы, оценки, ссылки, языки трейлеров и причины рекомендаций. Доказательства — `research/`.
- Плеер на телефоне сверху, на компьютере слева. Чтение не ставит видео на паузу.
- По явному запросу пользователя доступны четыре тёмных оформления: «Кино», «Нуар», «Список», «Неон». Переключатель сверху коллекций; выбор хранится отдельно в `dc-appearance-v1`. Палитры/сетки — `dist/appearance.css`, применение до первой отрисовки — `dist/ui/appearance.js`.

## Работа

Node ≥22: `npm run dev`, `npm test`, `npm run build`. Слои описаны в `ARCHITECTURE.md`.

Новое произведение добавляется записью из `content/addition.template.json`: `npm run add:title -- content/title.json`. Команда обновляет единый манифест, создаёт миграцию списка «Буду смотреть» при `planned: true` и собирает сайт.

Перед публикацией отправить точный commit, собрать и упаковать `.site-build/.openai` и `.site-build/dist`, сохранить и развернуть Sites-версию. Не терять `worker/` и D1-миграции. Лимит Worker — 10 MiB.

Редакторская замена: 20 сериалов и 10 фильмов с источниками 18+, английскими HD-трейлерами и конкретными причинами. 30 слабых соответствий исключены из рекомендаций, но не истории. Покрытие отзывами смотреть в актуальном `research/hdrezka-20-report.json`.

Обновление 20.10.2026: добавлены ровно 50 новых позиций (541–590), релиз `dark-humor-50-2026-10-20` один раз добавляется в сохранённую очередь. Автопополнения после оценок нет. Обновлённые ответы HDrezka содержат `depth`, `parentId`, `replyTo`; не выводить плоским списком и не выдумывать связи. Синопсис открывается с начала, сезоны и среднее число серий видны в ленте. На телефоне видео сразу под панелью фильтров (отступ 6 px).
