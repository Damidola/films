# Синхронизация телефона и ПК

1. Создай пустой **приватный** репозиторий `films-data`: https://github.com/new?name=films-data&visibility=private
2. Создай **fine-grained personal access token**: https://github.com/settings/personal-access-tokens/new
   - Repository access → Only select repositories → `films-data`.
   - Repository permissions → Contents → Read and write.
   - Срок действия выбери сам. После истечения токен нужно заменить.
3. На сайте открой «Каталог» и нажми строку «Только этот браузер · Настроить синхронизацию».
   Раскрой «Первое подключение GitHub», введи `Damidola/films-data` и токен, нажми «Подключить».
4. Снова открой синхронизацию → «Скопировать код». На втором устройстве вставь этот код в поле и нажми «Подключить».

Отметки обоих браузеров объединяются автоматически. Более новая реакция на один фильм имеет приоритет. Пустой новый браузер не удаляет существующие отметки. Открытая вкладка получает изменения каждые 15 секунд и при возвращении в неё.

Файл `films-profile.json` хранится только в выбранном приватном репозитории. Проверяется, что репозиторий приватный. Запись использует текущий SHA файла; при конфликте файл перечитывается и изменения объединяются заново.

**Код подключения содержит токен.** Передавай его только между своими устройствами; не отправляй в чат и не публикуй. Токен сохраняется локально в браузере, а не в исходниках. Предпочтителен отдельный токен только для `films-data`. Отозвать его можно в GitHub Settings.

Без подключения облака доступны кнопки «Сохранить отметки» и «Загрузить отметки». Импорт объединяет записи по времени и поддерживает резервную копию прежней базы.
