# Архитектура

Один репозиторий `/workspace/films`, один HTML-шаблон, одна каноническая библиотека. Постоянный `rank` сохраняет связь с реакциями при обновлении данных.

| Слой | Назначение |
| --- | --- |
| `dist/domain/library.js` | Объединение источников, постоянные ID, дубликаты и допуск рекомендаций. |
| `scripts/library-data.mjs` | Одинаковая `/library.json` для браузера, сервера и реестра отзывов. |
| `dist/state.js` | Реакции, очередь, персонализация, миграции. |
| `dist/repositories/` | Загрузка библиотеки, синхронизация профиля, кэш отзывов. |
| `dist/ui/` | Общие карточки, описание и отзывы для всех коллекций. |
| `dist/app.js` | Маршруты, события, жесты и постоянные плееры. |
| `worker/profile.mjs` | Общий профиль единственного пользователя в D1 через `/api/profile`. |
| `worker/reviews/` | Проверка источников, публичные адаптеры, кэш настоящих отзывов. |
| `worker/index.mjs` | HTTP API и статика. |

## Профиль и подборка

При запуске библиотека и серверный профиль загружаются параллельно. Нейтральный загрузчик скрывает незавершённый интерфейс. Реакции объединяются с локальным кэшем и синхронизируются с D1 без регистрации. Это общий профиль сайта.

«Любимое» — интерес к трейлеру, «Годнота» — просмотренное и понравившееся. Оба сигнала меняют состав и порядок рекомендуемой двухсотки; просмотренное весит больше. Предзагруженные трейлеры сами не создают новые произведения: новые кандидаты добавляются отдельным обновлением данных.

Каталог показывает нерешённые по номеру; лента — случайно. Реакция исключает из нерешённых; вертикальный пропуск откладывает в конец. Редакторское исключение не является пользовательским дизлайком и сохраняет историю.

Допуск: год ≥2000, IMDb ≥6, английский трейлер ≥720p, прямая страница HDrezka; российские/советские производства исключены. Для взрослого пополнения сохранён источник 18+. Возрастная маркировка не считается сходством вкусов и сама не обещает наготу.

## Видео и отзывы

Три постоянных слота прогревают соседние трейлеры. Ручная пауза сохраняется при смене раздела. Описание и отзывы не останавливают видео. На телефоне чтение под плеером; на компьютере справа.

Отзывы привязаны к проверенному произведению. HDrezka читается через публичный AJAX, до 20 отзывов. `allAvailable` обозначает все доступные, когда их меньше. Чужие снимки отвергаются, ошибки не заменяются выдуманными текстами. Основные отзывы HDrezka встроены в сборку; архивные комментарии YouTube доступны через адаптер по запросу.

## Сопровождение

`npm run dev` — локальный сервер; `npm test` — домен/API; `npm run build` — Worker с проверкой лимита 10 MiB. Браузерные сценарии — `tests/`. Доказательства источников — `research/`.

`scripts/refresh-adult-discovery.mjs` воспроизводит пополнение из проверенных метаданных, возрастов, провайдеров и трейлеров. `scripts/refresh-hdrezka-reviews20.mjs [selection.json]` обновляет отзывы, ограничивает частоту и останавливается при 403/429.

### Ручные добавления одним файлом

`content/manual-additions.json` — единый источник новых вручную подобранных фильмов и сериалов: карточка, подтверждённая страница KinoGo, страница и снимок отзывов HDrezka, а также отметка «Буду смотреть». Для нового названия заполнить `content/addition.template.json` и запустить `npm run add:title -- content/new-title.json`. Команда назначает rank, обновляет единый манифест, создаёт D1-миграцию при `planned: true` и сразу собирает сайт. Остаётся обычная публикация. Сбор сведений с внешних сайтов — отдельная исследовательская часть; для интеграции не нужно вручную править разрозненные реестры.
